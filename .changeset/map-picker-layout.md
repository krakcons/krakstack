Add a controlled GoogleMapPicker with responsive toolbar layout, floating suggestions, configurable radius presets, localized source notices and a yellow default confirmation action. Keep lookup and persistence host-owned. GoogleMap radius fitting waits for updated overlays to paint and cancels stale scheduled fits.

The default confirmation colour uses KrakStack's `oklch(0.9247 0.0524 66.1732)` rather than Tailwind yellow.
