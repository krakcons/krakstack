# Valeur à copier

Un champ en lecture seule avec retour de copie et sélection au focus, inspiré du CopyableInput de Kokobi. Les valeurs sont visibles par défaut. Activez `secret` pour masquer la valeur et proposer la révélation avec masquage automatique facultatif.

## Installation

```bash
bunx shadcn@latest add @krak-stack/copy-value
```

## Utilisation

```tsx
import { CopyValue } from "@/components/ui/copy-value";

<CopyValue value={url} label="URL" />;
<CopyValue value={apiKey} label="Clé API" secret />;
```

Import du paquet : `@krak-stack/registry/copy-value`.

## Exemples

### Sans bordure

```tsx
<CopyValue value={apiKey} label="Clé API" secret variant="ghost" />
```

La variante ghost retire la bordure, le fond et l’ombre, utilise une police à chasse fixe et un bouton de copie avec icône seule, tout en conservant les indicateurs de focus au clavier.

### Masquage automatique sans copie

```tsx
<CopyValue
  secret
  value={token}
  label="Jeton temporaire"
  autoHideDelay={5000}
  copyable={false}
/>
```

### Actions désactivées

```tsx
<CopyValue value={apiKey} label="Clé API" secret disabled />
```

La désactivation masque le secret révélé et bloque le champ et les actions. Remplacer `value` ou modifier `secret` réinitialise la révélation. Les valeurs non secrètes restent visibles même lorsque le champ est désactivé.

## Référence

| Propriété       | Type                            | Valeur par défaut               |
| --------------- | ------------------------------- | ------------------------------- |
| `value`         | `string`                        | Obligatoire                     |
| `label`         | `string`                        | Contexte accessible obligatoire |
| `secret`        | `boolean`                       | `false`                         |
| `variant`       | `"outline" \| "ghost"`          | `"outline"`                     |
| `copyable`      | `boolean`                       | `true`                          |
| `autoHideDelay` | Millisecondes                   | `0` (désactivé)                 |
| `disabled`      | `boolean`                       | `false`                         |
| `className`     | `string`                        | —                               |
| `locale`        | `string`                        | Langue du fournisseur           |
| `messages`      | Libellés partiels par langue    | Valeurs intégrées               |
| `copyMessages`  | `CopyButtonMessageTranslations` | Valeurs du bouton de copie      |

Clés de messages : `show`, `hide` et `hidden`. La langue exacte est prioritaire sur la langue de base. Les valeurs anglaises et françaises sont incluses.

## Accessibilité

Le champ en lecture seule possède un libellé et sélectionne son contenu au focus. Le mode secret utilise un champ de mot de passe et un bouton de révélation avec `aria-pressed`. La copie utilise le bouton accessible existant. Les actions ne soumettent pas les formulaires.

## Sécurité et intégration

Le masquage n’est ni du chiffrement, ni une autorisation, ni une protection contre l’inspection du navigateur. Ne fournissez que des valeurs autorisées pour la personne. N’insérez jamais de vrais identifiants dans les exemples, URL, journaux, statistiques ou erreurs. Le composant ne récupère et ne conserve aucun secret.
