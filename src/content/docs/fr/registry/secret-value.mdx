# Valeur masquée

Une chaîne initialement masquée avec révélation, masquage automatique facultatif et retour de copie. Adaptée de l’affichage de secrets de Kokobi.

## Installation

```bash
bunx shadcn@latest add @krak-stack/secret-value
```

## Utilisation

```tsx
import { SecretValue } from "@/components/ui/secret-value";

<SecretValue value={apiKey} label="Clé API" />;
```

Import du paquet : `@krak-stack/registry/secret-value`.

## Exemples

### Masquage automatique sans copie

```tsx
<SecretValue
  value={token}
  label="Jeton temporaire"
  autoHideDelay={5000}
  copyable={false}
/>
```

### Actions désactivées

```tsx
<SecretValue value={apiKey} label="Clé API" disabled />
```

La désactivation masque la valeur et bloque les actions. Remplacer `value` masque immédiatement la nouvelle valeur.

## Référence

| Propriété       | Type                            | Valeur par défaut               |
| --------------- | ------------------------------- | ------------------------------- |
| `value`         | `string`                        | Obligatoire                     |
| `label`         | `string`                        | Contexte accessible obligatoire |
| `copyable`      | `boolean`                       | `true`                          |
| `autoHideDelay` | Millisecondes                   | `0` (désactivé)                 |
| `disabled`      | `boolean`                       | `false`                         |
| `className`     | `string`                        | —                               |
| `locale`        | `string`                        | Langue du fournisseur           |
| `messages`      | Libellés partiels par langue    | Valeurs intégrées               |
| `copyMessages`  | `CopyButtonMessageTranslations` | Valeurs du bouton de copie      |

Clés de messages : `show`, `hide` et `hidden`. La langue exacte est prioritaire sur la langue de base. Les valeurs anglaises et françaises sont incluses.

## Accessibilité

Le bouton expose `aria-pressed`. Le texte masqué annonce une valeur cachée, sans son contenu ni sa longueur. La copie utilise le bouton accessible existant. Les actions ne soumettent pas les formulaires.

## Sécurité et intégration

Le masquage n’est ni du chiffrement, ni une autorisation, ni une protection contre l’inspection du navigateur. Ne fournissez que des valeurs autorisées pour la personne. N’insérez jamais de vrais identifiants dans les exemples, URL, journaux, statistiques ou erreurs. Le composant ne récupère et ne conserve aucun secret.
