# Support Dialog

Use `SupportDialog` to collect a message and optional screenshots. Users can choose files or paste screenshots into the message field. The dialog accepts up to three PNG, JPEG, or WebP images of up to 5 MiB each. Your app decides how to send the request.

```bash
bunx shadcn@latest add @krak-stack/support-dialog
```

```tsx
import { SupportDialog } from "@/components/support-dialog";

<SupportDialog onSubmit={sendSupportRequest} />;
```

The package export is `@krak-stack/registry/support-dialog`. Pass a custom button via `trigger` if you want to choose its placement or styling.

English and French messages are built in. The dialog follows `KrakstackProvider` unless you pass `locale`. To customize individual strings, pass overrides keyed by locale, for example `messages={{ en: { title: "Contact support" } }}`.

`onSubmit` receives `{ message, attachments, replyEmail? }`, where `attachments` is a list of `File` objects. Set `askForReplyEmail` for signed-out users. For signed-in users, resolve the reply address from the session on the server. Resolve the callback when the request has been accepted, or throw to retain the draft for retry.

Use multipart form data to send files to your server. Apply request and upload limits on the server, use `SupportRequestSchema` to validate the parsed payload, and verify image contents rather than trusting the declared MIME type. Keep credentials and destination selection on the server, and don't include request contents in telemetry. The dialog does not collect URLs, account details, or diagnostics automatically.
