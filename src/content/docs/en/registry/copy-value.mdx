# Copy Value

A read-only input with clipboard feedback and select-on-focus, modeled on Kokobi’s CopyableInput. Values are visible by default. Set `secret` to mask the value and enable reveal/hide with optional auto-hide.

## Installation

```bash
bunx shadcn@latest add @krak-stack/copy-value
```

## Usage

```tsx
import { CopyValue } from "@/components/ui/copy-value";

<CopyValue value={url} label="URL" />;
<CopyValue value={apiKey} label="API key" secret />;
```

Package import: `@krak-stack/registry/copy-value`.

## Examples

### Borderless

```tsx
<CopyValue value={apiKey} label="API key" secret variant="ghost" />
```

The ghost variant removes the border, background and shadow, uses monospaced text and an icon-only copy button, and keeps keyboard focus indicators.

### Auto-hide without copying

```tsx
<CopyValue
  secret
  value={token}
  label="Temporary token"
  autoHideDelay={5000}
  copyable={false}
/>
```

### Read-only availability

```tsx
<CopyValue value={apiKey} label="API key" secret disabled />
```

Disabling hides a revealed secret and disables the input and both actions. Replacing `value` or changing `secret` resets revelation. Non-secret values remain visible when disabled.

## API reference

| Prop            | Type                            | Default                     |
| --------------- | ------------------------------- | --------------------------- |
| `value`         | `string`                        | Required                    |
| `label`         | `string`                        | Required accessible context |
| `secret`        | `boolean`                       | `false`                     |
| `variant`       | `"outline" \| "ghost"`          | `"outline"`                 |
| `copyable`      | `boolean`                       | `true`                      |
| `autoHideDelay` | `number` in milliseconds        | `0` (off)                   |
| `disabled`      | `boolean`                       | `false`                     |
| `className`     | `string`                        | —                           |
| `locale`        | `string`                        | Provider locale             |
| `messages`      | Locale-keyed partial labels     | Built-in defaults           |
| `copyMessages`  | `CopyButtonMessageTranslations` | Copy Button defaults        |

Message keys: `show`, `hide` and `hidden`. Exact-locale overrides take precedence over base-language overrides. English and French defaults are included.

## Accessibility

The read-only input is labeled and selects its contents on focus. Secret mode uses a password input and a reveal button exposing `aria-pressed`. Copy uses the existing accessible Copy Button. Both actions are non-submit buttons.

## Security and integration

Masking is not encryption, authorization, or protection from browser inspection. Only supply a value the viewer may receive. Do not place real credentials in examples, URLs, logs, analytics or error messages. The component does not fetch or persist secrets.
