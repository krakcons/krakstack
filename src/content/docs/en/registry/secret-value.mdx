# Secret Value

An initially masked string with reveal/hide, optional auto-hide and clipboard feedback. Adapted from Kokobi’s secret display.

## Installation

```bash
bunx shadcn@latest add @krak-stack/secret-value
```

## Usage

```tsx
import { SecretValue } from "@/components/ui/secret-value";

<SecretValue value={apiKey} label="API key" />;
```

Package import: `@krak-stack/registry/secret-value`.

## Examples

### Auto-hide without copying

```tsx
<SecretValue
  value={token}
  label="Temporary token"
  autoHideDelay={5000}
  copyable={false}
/>
```

### Read-only availability

```tsx
<SecretValue value={apiKey} label="API key" disabled />
```

Disabling hides a revealed value and disables both actions. Replacing `value` hides the new value immediately.

## API reference

| Prop            | Type                            | Default                     |
| --------------- | ------------------------------- | --------------------------- |
| `value`         | `string`                        | Required                    |
| `label`         | `string`                        | Required accessible context |
| `copyable`      | `boolean`                       | `true`                      |
| `autoHideDelay` | `number` in milliseconds        | `0` (off)                   |
| `disabled`      | `boolean`                       | `false`                     |
| `className`     | `string`                        | —                           |
| `locale`        | `string`                        | Provider locale             |
| `messages`      | Locale-keyed partial labels     | Built-in defaults           |
| `copyMessages`  | `CopyButtonMessageTranslations` | Copy Button defaults        |

Message keys: `show`, `hide` and `hidden`. Exact-locale overrides take precedence over base-language overrides. English and French defaults are included.

## Accessibility

The reveal button exposes `aria-pressed`. Masked text announces a hidden value rather than its contents or length. Copy uses the existing accessible Copy Button. Both actions are non-submit buttons.

## Security and integration

Masking is not encryption, authorization, or protection from browser inspection. Only supply a value the viewer may receive. Do not place real credentials in examples, URLs, logs, analytics or error messages. The component does not fetch or persist secrets.
